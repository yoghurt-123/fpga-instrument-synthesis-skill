# WAV 分析与参数提取

## 输入与对齐

- 读取真实文件头：采样率、声道、PCM/浮点格式、有效位数、大小端及数据块位置。WAV 头不一定固定为44字节。
- 24位PCM需正确符号扩展。多声道先检查声道相位，避免直接求平均导致抵消。MP3可在电脑上解码，但转换为WAV不会恢复有损压缩丢失的信息。
- 浮点分析统一到满幅±1；整数PCM转浮点时按有效位宽缩放。dBFS用统一参考值，不比较一个整数RMS和另一个归一化RMS。
- 用短窗能量加噪声底门限定位实际起音，并回查波形，保留拨弦/敲击瞬态。记录原文件偏移与重采样后的偏移，避免重复裁切。
- 文件时长、非零样本时长和听得见的音长分别记录。尾部补零或人为淡出不能当作真实乐器的自然衰减。

## 分音与包络

1. 稳态段估计基频，结合自相关/频谱避免把强二次谐波当作基频。
2. 用重叠时窗或围绕分音的解调包络估计幅度随时间变化。低音分音的窗长要覆盖足够周期，不能拿几毫秒FFT可靠区分相邻低频分音。
3. 记录每个有效分音的频率、相位参考点、峰值、上升时间和衰减曲线。钢琴与吉他可能有非整数倍分音，不强行把所有峰值吸附到整数谐波。
4. 在起音、早期衰减和尾段分别拟合；允许不同分音有不同上升与衰减。对噪声底附近、拍频明显或拟合质量差的分音降权，不硬套单一指数。
5. 按各分音独立门限筛选；遇到一个弱分音不能立即结束搜索，后面可能还有强分音。相位应随时间原点变化同步换算。

指数包络：`A(t)=A0*exp(-t/tau)`。若用定点递推

`A[n+1] = A[n] - ((A[n] * code) >> Q)`

则 `code=round(2^Q*(1-exp(-1/(Fs*tau))))`。
当系数很小时，`tau≈2^Q/(Fs*code)`；每秒衰减dB约为 `8.686/tau`。
改变采样率后重新计算系数及所有时间计数，不能只改输出文件头。

## 试听与质量判据

- 同时提供固定增益的数值对比和必要的听感响度匹配版本；标明是否归一化，不能逐文件归一化后宣称尾音变弱。
- 对齐后比较起音、中段、尾段的RMS、峰值、直流偏置、削波样本数、频谱和分音包络。
- 离线脚本必须说明采用浮点近似还是逐拍定点仿真。离线滤波器实际启用、RTL却旁路时，不能把两者当作一致实现。
- 无听辨能力时只报告数值与波形证据，请用户试听确认“明亮”“鼻音”“轰鸣”等主观目标。
- 不把第三方录音自动打包到公开仓库。记录来源，并检查使用与再分发许可。
