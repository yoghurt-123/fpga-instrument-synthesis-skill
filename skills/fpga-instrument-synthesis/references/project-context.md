# 本项目经验：可迁移方法与历史参数

以下是2026-10-04会话中的项目实例，使用前读取目标工程确认现状。此文件不构成最新工程配置或硬件接线依据。

- Tang Mega 60K，禁止软核；内部时钟名义52.5MHz，采样间隔1088时钟，名义Fs约48253.676Hz。内部振荡器的实际误差会影响音高与时序，不能把名义值当实测值。
- TTP229负责触摸事件；DAC路径使用PT8211，VOFA为观察通道。保留原按键/触摸行为是常见约束。
- 钢琴：12个分音、每分音独立包络、短弱敲击噪声，一条运算通路按顺序处理分音。参数来自录音离线分析，不把全部WAV放入FPGA。
- 吉他：3个独立弦声部，每弦12分音，共享计算；E2单音及E2/B2/E3组合用于验证。不是完整六弦最终实现。
- 曾出现旧离线报告起音错位、整数/浮点幅度单位不一致、试听脚本与RTL滤波旁路不同；不能把这些旧报告的数字直接当作正确参数。
- 曾尝试同时改变高通、乘法精度及低阶衰减，用户不喜欢整体音色变化。后续优先小范围保留满意的前段与过载处理。

## 最近一次实际修改的候选参数

`GTR_SAMPLES=193015`（约4秒）、`TAIL_START=120634`（约2.5秒）、`TAIL_SHIFT=5`。
低两分音在1秒后逐渐增加衰减系数，`LOW_TAIL_ADD=160`；过载后置Q8增益从68改为96（约+3dB）。

当时单音RTL仿真：前1秒音源逐样本一致，3～4秒平均功率相对旧版约-13.6dB，结束后归零。此结果仅针对当时版本和测试音，不代表主观音色已被认可。

后来提出“起音带鼻音/公鸭嗓、上限3.5秒”，这是新的试听目标，尚不能写成已验证结论。此前6秒原音片段在3.5秒后为零，也不能据此推断原始完整录音只有3.5秒声音。
