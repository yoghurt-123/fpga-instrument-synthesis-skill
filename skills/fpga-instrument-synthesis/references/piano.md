# 钢琴音

## 低存储实现

`音符事件 → 多分音DDS → 每分音独立包络 → 求和 → 最终释放/静音 → PCM输出`

用一张共享正弦表，保存各分音的频率步进、初始相位、峰值、起音时间及衰减系数。8～12个分音可以作为资源有限时的起点，最终数量取决于参考录音、最高音的奈奎斯特限制和可用运算周期。

相位步进：`step=round(f*2^P/Fs)`，相位累加器位宽为P；查表通常取相位高位。以实际音频采样节拍计算Fs。

## 音色调整

- 钢琴的辨识度来自敲击后的频谱演变。高分音通常比低分音衰减快，但比例应由具体录音或试听决定。
- 起音过软：检查高分音建立速度以及被裁掉的敲击瞬态；先改分音包络，不先整体加音量。
- 过于像正弦/闷：检查低阶占比、高阶有效精度及高阶过早消失。不要把“尾音降低”误写为音高降低。
- 低频尾音过重：适量增加低阶尾段衰减，或者按音龄逐渐增加衰减率，保持包络连续。
- 可用很弱、很短的滤波噪声模拟击弦声；噪声过大会变成咔嗒或杂音，应单独试听控制。
- 真实钢琴可能存在弦间拍频、非谐性和踏板共鸣。先满足单音目标，有资源和明确需求时再增加这些细节。

## 音符与复音

- 音名必须含八度；例如C4与C5是不同频率，黑键是半音，不是相邻白键的和弦。
- 同一个音色模型可按频率表移调，但跨较大音域时分音比例、衰减、非谐性应分区调整。
- 和弦由多个独立声部同时求和，每声部保留自己的包络和释放。不能把共享的单音相位/年龄直接用于所有音符。
- 扫描到的真实按键事件可立即发声，不必为了整齐强制等待其他键；若要求小于10ms，触摸扫描、去抖与音频等待都计入预算。
- 一次触发固定音长与按住持续/松开释放是不同交互，沿用用户指定方式。不存在通用的“标准电子琴音长”。
