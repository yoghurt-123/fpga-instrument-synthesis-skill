# 电吉他清音与过载

## 声部与音高

标准定弦从第6到第1弦为E2、A2、D3、G3、B3、E4，对应MIDI 40、45、50、55、59、64。

`note = open_note[string] + fret`，`f=440*2^((note-69)/12)`。
同音高在不同弦上也可能音色不同；频率表可共享，弦的包络/音色参数可区分。不要为每个品位复制一份采样或合成器。

建议接口保留弦号、品位、拨弦事件、力度和制音事件，便于后续可视化接入；按项目需要实现其中字段。

## 清音基础

优先选择单音、音高已知、录音条件清楚的参考。和弦与单音采用同一音源体系，避免把外部和弦录音直接当另一套音色混入。

可选实现：录音参数驱动的分音合成，或经过阻尼/激励设计的Karplus–Strong等物理建模。已有DDS音源表现良好时，优先在原结构中优化。

清音不应机械套用钢琴参数：拨弦位置、拾音器位置造成的分音缺口、短促瞬态和分音的相对变化都影响吉他辨识度。

“公鸭嗓/鼻音/拨弦感”是听感描述，不是固定滤波频率。先对齐起音，检查前几十到几百毫秒的分音变化；可尝试短暂分音增强后衰减，必要时补极弱的滤波噪声。保留即时发声，不把整个起音延迟100ms来模拟瞬态。

## 效果链

常见结构：`各弦清音求和 → 前级滤波 → 驱动增益 → 非线性过载 → 音箱滤波 → 后置音量`。

- 前级增益改变失真程度；后置增益主要改变响度。用户满意过载但觉得音量低时，先检查并调整后置增益及混音余量。
- 非线性之前按弦处理和混合后统一处理会产生不同结果；和弦先混合再过载会产生互调，必须用和弦试听。
- 数字非线性可能产生混叠；按资源选择过采样、适度预滤波或较温和驱动，不能承诺一个低通能消除已折叠的混叠。
- 用户认可的效果链作为对比基线。发现旁路、截位等问题时，先验证与实际听感的关系，分步修正；不要一次重写全部滤波和定点结构。

## 尾音、制音与切换

- 尾音轰鸣先查低分音衰减是否远慢于其他分音，再查过载压缩、直流偏置、滤波状态残留和输出未归零。
- 优先在一定音龄后连续增加低阶衰减，保留起音。缩短总时长只能减少拖尾持续时间，不能替代分音平衡调整。
- 发声上限按需要选择，例如3.5或4秒是项目试听方案，不是吉他标准。缩短时长不改变相位步进、Fs或前段瞬态速度。
- 制音采用短暂平滑释放；松手/制音后包络、声部状态应可靠归零。最终淡出通常作用于输出包络，反复把线性淡出系数乘回包络状态会导致远快于线性的衰减。
- 过载切换可以采用增益平滑或短交叉淡化，具体依据交互要求；避免突然切断音频，或等待整段4秒播放完才响应。
