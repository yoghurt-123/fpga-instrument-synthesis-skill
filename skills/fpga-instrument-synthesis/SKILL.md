# FPGA 钢琴与电吉他合成

目标：把参考录音中的音高、分音比例和随时间变化的音色，转成可调、可验证的 FPGA 合成参数。支持纯 RTL；不能使用软核时，离线电脑分析仍可使用 Python、MATLAB 等工具。

## 先确认当前任务

- 阅读项目说明、顶层、音源、参数表、效果链和输出接口。以实际代码为准，不把注释、历史报告或旧试听当作当前实现。
- 确定目标是钢琴、吉他清音、吉他过载，还是只做分析/生成交接说明。用户只要求思考或交接时，不修改工程。
- 确认时钟、实际采样率、PCM 位宽、当前复音数、资源余量、触发方式以及参考文件。已有信息足够时直接工作。
- 项目通常使用英文文件名、中文注释；尊重用户现有命名习惯。优先修改现有模块，新增文件要有明确用途。

## 工作方法

1. **锁定对比条件。** 记录修改前参数、参考音来源和用户喜欢的部分。只备份必要文件或使用已有版本控制；遵守用户是否需要备份的要求。
2. **先分析再拟合。** 对齐真实起音，统一幅度单位和采样率。先检查原录音、离线合成、RTL 仿真是否比较同一段声音。
3. **先完成一个音。** 按用户范围选择代表音；先改善一个听感维度，提供修改前后试听。确认后再推广到其他音和复音。
4. **复用计算。** 优先共享正弦查找表和时分复用乘法器，每个声部保留自己的相位、包络及触发状态。不要为每个品位复制音源模块。
5. **把参数做成可调项。** 区分音高、分音比例、起音时间、各段衰减、最终释放、前级驱动和后置音量。写出单位及增减方向。
6. **验证实际实现。** 离线试听只是候选；检查 RTL 定点输出、静音、重触发、复音削波和编译时序。未经播放或听辨工具验证，不声称已经听过音频。
