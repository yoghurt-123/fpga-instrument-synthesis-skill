# 最小可上板底鼓算法

目的：尽快验证C→合成→DAC，随后用参考WAV改进。不是已经拟合出的原声鼓，不保证初版听感达到录音。初版只有下降音高的正弦主体，先不实现噪声和多模态。

## 初始参数（工程起点，可调整）

Fs=52500000/1088 Hz；相位32位；使用当前256点signed16正弦表。初始频率90Hz，尾段50Hz；音高时间常数35ms；幅度时间常数120ms；起音1ms；总时长600ms；尾部/取消/重触发释放64采样。峰值幅度先设0.25满幅，给混音留余量。这些均为人工初始值，不标记为录音拟合结果。

参数在离线/ elaboration 前计算成整数常量，运行时不执行exp或浮点：

```
STEP_END = round(50 * 2^32 / Fs)
DELTA_INIT = round((90-50) * 2^32 / Fs)
C_PITCH = round(2^24 * (1-exp(-1/(Fs*0.035))))
C_AMP   = round(2^24 * (1-exp(-1/(Fs*0.120))))
N_ATTACK = round(0.001*Fs)
N_TOTAL  = round(0.600*Fs)
```

kick_params.vh为初版唯一参数源，测试和RTL共同包含。未来WAV拟合后由生成器更新该文件，不手工维护两套系数。

## 每采样递推

状态：phase uint32、delta uint32、amp uint24表示无符号Q0.24、age、attack_gain Q0.16（需17位以表示65536）、release_gain（0..64）、active，以及一个pending命令和力度。

```
step = STEP_END + delta
phase_next = phase + step       // 32位模回绕
delta_next = delta - ((uint64(delta)*C_PITCH)>>24)
amp_next = amp - ((uint48(amp)*C_AMP)>>24)
```

delta低于一个相位步长单位的物理误差可忽略，但不能越减越负。总时长终止保证幅度截断残留不永久发声。默认amp起点为2^22（0.25），力度只在触发时锁存，按现有code+1/16规则用足宽乘法缩放。

起音gain以商余数整数斜坡在N_ATTACK采样内从0准确走到65536；不是除法每拍运行。总时长最后64采样，以及取消/重触发时，release_gain从64递减到0。缩放量必须先扩位，禁止16位乘法溢出后再扩位。

```
modal = (signed(sine16) * signed({0,amp24})) >>> 24
attacked = (modal * attack_gain) >>> 16
pcm = (attacked * release_gain) >>> 6
```

乘积分别保留足够位数；最终写16位前检查/饱和。初始相位0、起音gain0避免阶跃。同步正弦ROM读延迟一拍，幅度/增益元数据同行流水；完成本样本后固定时刻提交，不错配下一采样的状态。周期远小于1088仍须给出实际调度表。

## 事件规则

- 空闲C按下：锁存力度，清相位/age、初始化delta/amp，开始起音。
- 正在响时再次C：保留一个新命令，旧声64采样平滑释放后启动；释放期间又来C，采用最新力度覆盖待触发命令并计数，明确首版不是无损滚奏队列。
- Esc/断连优先：清pending，旧声短释放；同拍C忽略，之后不得补发。重连先松开再按。
- 普通C松开不释放；按住不自动重复；F3不改变本引擎状态。
- PCM只在帧完成时更新，inactive输出0。检查取消发生在流水各级的情况，不允许旧提交复活声音。

## 最小验证

用整数参考递推验证phase/delta/amp和增益；检查正弦ROM元数据对齐、初末采样、非零音频、峰值、自然结束、重触发和取消。固定种子噪声不存在于初版，无需先生成整套噪声数据。

之后改善音色时，按WAV提取的主频/包络替换常量，并可增加同一幅度单位下的短带限击打噪声。额外支路必须单独验证定点缩放，不把±1浮点噪声直接加到±32767 PCM。
