## 1. 澄清“12个谐波多少个点”

历史钢琴是12个分音；当前吉他是每声部24个分音、6槽扫描。sine_wave.v为共享256点、16位有符号正弦表，同步读延迟一拍。每个分音保存相位、频率、幅度、包络参数，不各自保存一段WAV。

32位DDS：`step=round(f*2^32/Fs)`，相位累加后以高8位查正弦表。表的256点是相位分辨率，不是每个分音每周期必须输出256点。查表、相位更新和幅度乘法按实际ROM延迟对齐。FFT分析窗长是另一独立参数。

## 2. 分期与参考素材

首批：底鼓、军鼓、闭合踩镲。第二批：开放踩镲、Crash、一个Tom，共6种。最终：三个Tom加Ride，共9种。音色数不等于发声槽数；首批建议4个活动槽，支持三鼓叠加和一次重复打击尾音，后续按滚奏和镲片长尾评估扩展。

参考链接：

- [DrumThrash原声鼓](https://www.drumthrash.com/free-drum-samples.html)：24bit/48k WAV，优先干声/近场；演示有多采样混合，不等于单个WAV。
- [MusicRadar 1000 drums](https://www.musicradar.com/news/drums/1000-free-drum-samples)：hits/kits是WAV，另有REX循环；不允许重新分发素材。
- [AVL Drumkits](https://www.bandshed.net/avldrumkits/)：多力度层，SFZ包含采样，CC BY-SA 3.0。
- [99Sounds](https://99sounds.org/drum-samples/)：加工/电子鼓对比参考。

同一套鼓优先各取轻、中、重力度；多麦克风轨不等于力度层，第一轮只用一个明确轨。记录来源、许可、文件哈希、原始增益，不上传第三方录音。本项目赛题要求实时合成，WAV用于分析/试听，不把整段PCM放进FPGA播放。

## 3. WAV分析算法

解析实际RIFF块与位深，不假设44字节头；24位PCM正确符号扩展。检查声道相位，避免平均抵消。去直流、估计噪声底、短窗能量定位起音，保留击打瞬态。保存未归一化版本比较力度。

1. 多分辨率STFT：起音512/1024点、鼓腔4096/8192点Hann窗，75%重叠作为起点。48k时窗长约10.7/21.3/85.3/170.7ms。低频用长窗区分峰，短瞬态辅以短窗/解调跟踪；补零不提高真实分辨率。
2. 跟踪稳定谱峰，提取每个模态f(t)、A(t)、起音相位和衰减。鼓膜模态不强制整数倍频。
3. 有效幅度区间拟合 `ln A(t)=b-t/tau`；避开噪声底，起音和尾段分开。轻重力度允许频移、噪声比例与亮度不同。
4. 重建模态后估计残差的频带能量与衰减，形成噪声支路。噪声不追求逐样本复现原录音。
5. 导出JSON：频率/相位/幅度/攻击时间/衰减/噪声带/力度映射/拟合误差。不是导出录音ROM。

## 4. 合成算法

统一模型：

```
y[n] = sum_m A_m[n]*sin(phi_m[n]) + sum_b E_b[n]*H_b{w_b[n]}
phi_m[n+1] = phi_m[n] + 2*pi*f_m[n]/Fs
A_m[n+1] = r_m*A_m[n], r_m=exp(-1/(Fs*tau_m))
```

各模态与各噪声带有独立包络，起音另有有限上升段。以下是待拟合的起始规模，不是实测参数：

|声音|模态候选|其他部分|
|---|---|---|
|底鼓|2–4|下降音高、短击打噪声|
|军鼓|4–8非谐波模态|2–3带限噪声，模拟响弦|
|闭/开踩镲|6–12金属模态|2–3中高频噪声带，各自包络|
|Tom|4–8|短瞬态与轻微音高变化|
|Crash/Ride|12–24|多频带噪声和独立长尾|

底鼓：`f[n]=f_tail+d[n]`，`d[n+1]=r_pitch*d[n]`。d初值取实测起始频率与尾段频率之差；RTL可直接递推相位步长差，不每样本计算指数。

军鼓：鼓腔模态与响弦噪声分开包络，不能只增大吉他噪声。踩镲不能只用12个整数谐波，也不能只有白噪声。Crash/Ride逼真度最难，先离线试听决定模态数，不能保证少量模态达到录音效果。

噪声候选：非零uint32 xorshift（左13、右17、左5，32位回绕），高16位解释为有符号值；不同声部不同种子，测试固定种子。低成本带通候选：

```
u[n] = u[n-1] + a_hi*(w[n]-u[n-1])
v[n] = v[n-1] + a_lo*(u[n]-v[n-1])
band[n] = u[n]-v[n]
a(fc) = 1-exp(-2*pi*fc/Fs), 0<fc_lo<fc_hi<Fs/2
```

这是匹配极点近似，fc不是精确数字-3dB点，需在实际Fs上检查频响。滤波后乘噪声包络；复杂双二阶滤波仅在音质需要时采用，并检查量化极点和中间位宽。

依据：[军鼓模态与噪声](https://www.soundonsound.com/techniques/synthesizing-drums-snare-drum)、[底鼓合成](https://www.soundonsound.com/techniques/practical-bass-drum-synthesis)、[镲片起音与尾音](https://www.soundonsound.com/techniques/synthesizing-realistic-cymbals)。具体硬件参数和流程是本项目建议，并非来源文章提供的已验证RTL。

## 5. 定点、资源与混音

Fs按52500000/1088≈48253.676Hz计算。输出标准48k试听文件需真正重采样，不能仅改WAV头。

- 相位uint32，正弦signed16，幅度至少24位含小数；乘积足宽、舍入再缩位。
- 包络可用 `A -= (A*c)>>24`，`c=round(2^24*(1-exp(-1/(Fs*tau))))`。量化尾部停滞用残差累加或低阈值短淡出终止，不留下无限微小尾音。
- M个分量累加至少额外ceil(log2 M)位，再计实际增益。统一末级缩放饱和，不逐分量削顶；滤波状态验证极限环、溢出、符号扩展。
- 独立鼓引擎时分复用运算，RAM存活动声部状态。共享正弦表的数值，不未经排程抢占旧音源ROM端口；必要时独立实例化小ROM。
- 周期预算：`C=槽数*(模态数*每模态周期+噪声带数*滤波周期+包络开销)+混音开销`。以1088拍为限，预留至少20%为设计目标，靠实际排程验证。吉他空隙505拍不等于全系统空闲预算。
- 当日资源快照：Logic41203/59904、Reg17384/60780、CLS26007/29952、BSRAM71/118、DSP74.5/118。CLS约86.8%，寄存器空余不能直接换算为新增功能容量。先测独立综合增量，再合入；网口MAC/缓存另做预算。
- 鼓绕过吉他过载。钢琴、效果后的吉他、鼓各自增益，按同一音频帧对齐后宽位混音，共用主音量与输出饱和。
- 三乐器并发要处理现有互斥模式/输出选择，并保留输入路由；不是单加一个mux。鼓关闭时旧PCM逐样本一致作为回归目标。

## 6. 事件与简单操作

统一命令：instrument、sound_id、velocity、sample_time、source、generation。参数事务锁存→槽准备→触发；键盘和未来网口使用相同入口，来源不能决定音高/音色参数是否有效。

队列深度与活动声部数分开。队列满拒绝并计数，不覆盖未消费命令。重复打击优先空闲槽，满槽对低包络尾音短淡出后替换，命令参数保留到提交。后续用实际滚奏评估声部数。

闭合踩镲只终止同choke组的开放踩镲，1–5ms释放作试听起点；不硬清所有声音。取消/断连/旧generation不复活命令。F3仅作用于吉他，不清鼓状态。

首版三鼓直接触发，具体键位读取最新映射后分配，不抢QWER/F3或其他在用键；不额外引入复杂模式。未来网口定义序号、过期事件、同步与缓冲，不直接按网络到包时间起音。

## 7. 实施与验收

A. 选参考后输出三鼓reference/float/fixed WAV及简单摇滚节奏；同时保留固定增益版和明确标注的响度匹配版。先定听感，不直接上RTL。

B. 检查频移、频带能量、包络、峰值/RMS、直流、削波、极限环。录音噪声不要求逐位相同；固定种子的定点模型与RTL应一致。

C. 独立RTL短测：单击、三鼓重叠、重复、队列满、choke、取消/复位；记录真实周期和综合资源。

D. 集成后验证鼓关闭旧输出一致，F3/QWER正常、混音不溢出。最后完整PnR检查全部时钟setup/hold和源代码/位流哈希；不过时序不烧录。未修改路径不反复跑整曲。

E. 后续三乐器并发与网口独立验收：排程、输入路由、混音余量、时钟域和最坏负载。不把鼓单模块PASS当作整机并发完成。
